## Решения

- Публичный бот: отвечать любому пользователю в личном чате.
- Поведение и тексты — по скриншотам существующего конвертера, не по схеме из трёх валют в `.env`.
- Стек: Python, aiogram 3.
- Выкладка: ZIP с Python-кодом, Cloud Functions, триггер Telegram, Lockbox для `BOT_TOKEN`, YDB Serverless для выбора валют и снимка курсов.
- Функция не публикуется в интернет. Её вызывает только сервисный аккаунт триггера. API Gateway не нужен.
- Локальный прогон — long polling. В Cloud Functions только обработчик одного объекта Update.
- Курсы: Frankfurter v2, без ключа, база USD. Запасной URL — fawazahmed0 exchange-api. ЦБ РФ и платные API не использовать.
- Облачные ресурсы создавать только после токена BotFather и каталога Yandex Cloud с биллингом.

Frankfurter отдаёт дневные курсы центральных банков, не рыночный mid. Суммы не совпадут с ботом на скриншотах: там `7.21 USD` даёт `555.24 RUB`. Это ожидаемо. Каталог из 30 кодов проверен по `https://api.frankfurter.dev/v2/currencies` 3 октября 2026: у всех `end_date` не раньше 2 октября 2026.

## Поведение

До `/start` любое сообщение отвечает текстом: нужно нажать `/start`, это настроит бота для пользователя.

`/start` создаёт запись пользователя, если её ещё нет, и показывает приветствие:

- бот представляется конвертером валют;
- перечисляет текущий выбор с флагами;
- даёт примеры `100 usd`, `250 rub`, `1000 lkr`;
- объясняет, что сумма пересчитывается в выбранные валюты, а совпавшая с выбором возвращается как есть;
- включает постоянную клавиатуру.

Команды меню бота: `/start`, `/set_currencies`, `/help`.

Постоянная клавиатура:

- «Дополнительные функции» отвечает короткой подсказкой про кнопки ниже. На скрине это сообщение «Используй кнопки ниже для управления ботом:».
- «Выбрать валюты» делает то же, что `/set_currencies`.
- «Помощь» делает то же, что `/help`: справка с примерами ввода.

`/set_currencies` открывает выбор валют:

- сверху счётчик «Выбрано N из 5» и выбранные валюты с названиями;
- выбранные валюты — кнопки с галочкой, по две в ряд, нажатие убирает валюту;
- на главном экране — регионы «Европа и СНГ», «Азия», «Ближний Восток», «Другие»;
- внутри региона выбранные остаются сверху, ниже доступны остальные валюты региона;
- «← Регионы» возвращает на главный экран, «Готово» закрывает выбор;
- изменения сохраняются сразу, добавление сохраняет порядок;
- шестую валюту добавить нельзя, последнюю убрать нельзя;
- регион передаётся в callback кнопки, поэтому переходы не требуют состояния в памяти процесса;
- старые callback `t:CODE` поддерживаются и открывают обновлённый главный экран.

Ввод суммы: число, затем код из каталога. Допустимы `7.21 usd` и `7,21 USD`. Пробел между суммой и кодом необязателен. Код не из каталога и неположительная сумма — сообщение об ошибке, без запроса курсов.

Ответ на сумму:

- заголовок вида «Конвертация 7.21 USD»;
- по строке на каждую выбранную валюту, в порядке выбора;
- если исходная валюта есть в выборе, её строка содержит ту же сумму и пометку «без конвертации»;
- остальные строки — эквивалент;
- тысячи отделяются запятой, дробная часть — точкой, всегда два знака: `2,228.61`.

Бот молчит в группах и каналах.

Повторная доставка того же `update_id` не должна второй раз переключить валюту. Контейнер отвечает успехом после обработки и отправки ответа. Переключение валюты атомарно с маркером update_id; для текстовых ответов остаётся окно аварийного завершения.

## Курсы

Один запрос Frankfurter v2: база USD, все 31 код. Кросс-курс между любыми двумя валютами считается через доллар.

Снимок хранится в YDB. Повторная загрузка, если снимку больше 6 часов. Если Frankfurter недоступен, используется последний снимок, и в ответе пользователю прямо сказано, что курс взят из сохранённой копии. Если снимка нет совсем, конвертация отвечает, что курсы сейчас недоступны.

Запасной URL fawazahmed0 вызывается только когда Frankfurter не ответил и сохранённого снимка нет. Источник снимка записывается рядом с датой наблюдения.

Дата курса в обычный ответ не добавляется: формат строки остаётся как на скрине.

## Размещение

Telegram → Telegram-триггер → Cloud Functions → YDB и Bot API.

Функция закрытая, вызывается сервисным аккаунтом триггера. Код упаковывается в ZIP, зависимости устанавливает YC. BOT_TOKEN подключён из Lockbox. Вход index.handler принимает один Update; выбранные валюты и снимок курсов хранятся в YDB.

Локально остаётся long polling. Docker и Container Registry не используются.

До выкладки нужны бот BotFather, платёжный аккаунт и каталог YC, настроенный yc. Скрипт deploy/setup.sh создаёт сервисный аккаунт, YDB, Lockbox и версию Cloud Function. Telegram-триггер настраивается через консоль после остановки локального polling. Инструкция: DOCS/CLOUD.md.

## Данные в YDB

`user_settings`:

- ключ `user_id`;
- `currencies` — порядок выбора, от 1 до 5 кодов каталога;
- `updated_at` — чтобы два быстрых нажатия не затёрли друг друга.

Нет строки — подставляется USD, LKR, RUB, EUR, THB и сразу записывается.

`fx_snapshot`, одна строка:

- курсы 31 валюты к USD;
- `rate_date` — дата наблюдения источника;
- `fetched_at` — когда снимок забрали;
- признак источника: Frankfurter или запасной URL.

Обработанные `update_id` хранить достаточно долго, чтобы повтор триггера не переключил валюту второй раз.

Локальный прогон пишет те же данные в память. Интерфейс хранилища один: смена реализации не меняет обработчики.

## Ограничения доставки

Переключение валюты и маркер update_id записываются одной транзакцией. Повтор callback может повторить редактирование, но не переключение. Для текстовых ответов запись маркера и отправка в Telegram не атомарны; гарантии единственной доставки после аварийного завершения нет.
