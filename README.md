# 💱 Telegram FX Bot

Telegram бот для конвертации валют с поддержкой множества валют и удобным интерфейсом.

## 🚀 Возможности

- 💱 Конвертация валют в реальном времени
- 🌍 Поддержка 27+ валют
- 🎯 Гибкая настройка: выбирай валюты для конвертации
- 🎨 Удобный интерфейс с inline-кнопками и кнопками меню
- 🏳️ Флаги стран для каждой валюты
- 💾 Сохранение настроек пользователей (персональные валюты для каждого)
- 📱 Постоянная клавиатура с командами для быстрого доступа
- 🔄 Автоматическая конвертация в выбранные валюты

## 📋 Требования

- Python 3.10 или выше
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

## 🔧 Установка

1. Клонируйте репозиторий или скачайте файлы:
```bash
cd tg_fx_bot
```

2. Создайте виртуальное окружение (рекомендуется):
```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

## ⚙️ Настройка

1. Получите токен бота у [@BotFather](https://t.me/BotFather) в Telegram

2. Установите переменную окружения с токеном:
```bash
# Linux/Mac
export TELEGRAM_BOT_TOKEN="your_bot_token_here"

# Windows (PowerShell)
$env:TELEGRAM_BOT_TOKEN="your_bot_token_here"

# Windows (CMD)
set TELEGRAM_BOT_TOKEN=your_bot_token_here
```

Или создайте файл `.env` (не забудьте добавить его в `.gitignore`):
```
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

3. (Опционально) Добавьте новые валюты в `currencies.py`:
```python
# Добавьте валюту в список AVAILABLE_CURRENCIES
AVAILABLE_CURRENCIES = [
    # ...
    "TRY",  # Турция (Turkish Lira)
]

# Добавьте флаг в словарь CURRENCY_FLAGS
CURRENCY_FLAGS = {
    # ...
    "TRY": "🇹🇷",  # Турция
}
```

## 💬 Использование

### Первый запуск

1. Найдите вашего бота в Telegram по имени, которое вы указали при создании
2. Отправьте команду `/start` для начала работы
3. Выберите валюты для конвертации через команду `/set_currencies`

### Конвертация валют

1. Напишите сумму и валюту в формате: `<сумма> <валюта>`
   - Можно указать **любую доступную валюту** на входе
   - Примеры: `100 usd`, `250.5 rub`, `1000 lkr`, `50 eur`

2. Бот автоматически конвертирует сумму в выбранные вами валюты
   - Если введенная валюта совпадает с выбранной - вернется та же сумма (без конвертации)

### Примеры

```
Вы: 100 usd
Бот: 💱 Конвертация 100.00 🇺🇸 USD:
     • 9,200.00 🇷🇺 RUB
     • 100.00 🇺🇸 USD (без конвертации)
     • 92.00 🇪🇺 EUR
```

```
Вы: 1000 rub
Бот: 💱 Конвертация 1000.00 🇷🇺 RUB:
     • 10.87 🇺🇸 USD
     • 10.00 🇪🇺 EUR
     • 3,500.00 🇱🇰 LKR
```

## 📝 Команды

- `/start` - Начать работу с ботом (обязательно при первом использовании)
- `/set_currencies` - Выбрать валюты для конвертации (до 5 валют)
- `/help` - Показать справку

### Кнопки меню

Бот предоставляет постоянную клавиатуру с кнопками:
- `/start` | `/set_currencies`
- `/help`

## 🎯 Особенности работы

### Выбор валют

- **На входе**: можно указать любую доступную валюту из списка
- **В настройках**: выбираются валюты, **в которые** будет конвертироваться ввод
- **Максимум**: можно выбрать до 5 валют для конвертации
- **По умолчанию**: RUB, LKR, USD (если пользователь не выбрал свои)

### Сохранение настроек

- Настройки каждого пользователя сохраняются в файл `user_settings.json`
- Настройки сохраняются между перезапусками бота
- Каждый пользователь имеет свои персональные настройки валют

### Флаги валют

- Каждая валюта отображается с флагом соответствующей страны
- Флаги показываются в результатах конвертации и на кнопках выбора

## 🔍 Как это работает

1. Пользователь отправляет сумму и валюту (например, "100 usd")
2. Бот парсит ввод и проверяет, что валюта доступна
3. Бот загружает настройки пользователя (выбранные валюты для конвертации)
4. Запрашивает актуальные курсы валют через API exchangerate-api.com
5. Конвертирует сумму во все выбранные валюты
6. Если введенная валюта совпадает с выбранной - возвращает ту же сумму
7. Отправляет результат с флагами валют

## 🛠️ Технологии

- **python-telegram-bot** - библиотека для работы с Telegram Bot API
- **requests** - для HTTP запросов к API курсов валют
- **exchangerate-api.com** - бесплатный API для получения актуальных курсов валют (без ключа)

## 🐛 Решение проблем

### Бот не отвечает
- Проверьте, что токен установлен правильно
- Убедитесь, что бот запущен
- Проверьте логи на наличие ошибок
- Убедитесь, что вы отправили команду `/start` при первом использовании

### Ошибка "Не удалось получить актуальный курс"
- Проверьте интернет-соединение
- API exchangerate-api.com может быть временно недоступен
- Попробуйте позже

### Неправильный формат ввода
- Используйте формат: `<сумма> <валюта>`
- Примеры: `100 usd`, `250.5 rub`, `1000 lkr`
- Убедитесь, что валюта есть в списке доступных

### Ошибка "Конфликт: уже запущен другой экземпляр бота"
- Остановите другие процессы бота: `pkill -f 'python.*bot.py'`
- Или найдите процессы вручную: `ps aux | grep 'python.*bot.py'`
